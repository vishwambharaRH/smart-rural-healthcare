# Smart Rural Healthcare Outreach Management System  
## User Stories & System Stories

---

## User Stories

### Patient Stories
- As a **patient**, I want to register in the system so that my medical details are stored digitally.
- As a **patient**, I want to view nearby health camps so that I can attend one conveniently.
- As a **patient**, I want to book an appointment with a doctor so that I receive medical consultation.
- As a **patient**, I want to view my medical records so that I can track my health history.
- As a **patient**, I want to receive notifications about upcoming appointments and health camps so that I do not miss them.
- As a **patient**, I want to view my prescriptions so that I can follow the treatment correctly.

---

### Doctor Stories
- As a **doctor**, I want to view my scheduled appointments so that I can manage my time efficiently.
- As a **doctor**, I want to access a patient’s medical history so that I can make informed decisions.
- As a **doctor**, I want to record diagnoses so that patient conditions are documented.
- As a **doctor**, I want to generate prescriptions so that patients receive proper treatment.
- As a **doctor**, I want to participate in health camps so that I can provide outreach healthcare.

---

### Health Worker Stories
- As a **health worker**, I want to register patients so that rural patients without technical access are included.
- As a **health worker**, I want to manage health camp logistics so that camps run smoothly.
- As a **health worker**, I want to notify patients about camps so that participation increases.

---

### Administrator Stories
- As an **administrator**, I want to manage users so that only authorized users access the system.
- As an **administrator**, I want to schedule health camps so that healthcare reaches rural areas.
- As an **administrator**, I want to generate reports so that healthcare outcomes can be evaluated.

---

## System Stories

- As a **system**, I should authenticate users so that data remains secure.
- As a **system**, I should store medical records persistently so that patient history is not lost.
- As a **system**, I should prevent appointment conflicts so that doctors are not double-booked.
- As a **system**, I should send notifications automatically so that users are informed in time.
- As a **system**, I should enforce role-based access so that users only perform permitted actions.

---

## Non-Functional Stories

- As a **user**, I want the system to be easy to use so that even non-technical users can operate it.
- As a **user**, I want the system to respond quickly so that tasks are completed without delay.
- As a **user**, I want my medical data to be secure so that privacy is maintained.
- As a **developer**, I want the system to be modular so that future changes are easy to implement.
